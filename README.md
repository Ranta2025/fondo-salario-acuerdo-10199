# Fondo de salario - Acuerdo 10199/2025

Aplicación de escritorio, local y sin conexión, para distribuir el fondo de salario no ejecutado
entre los trabajadores de una unidad presupuestada y exportar los cálculos a Excel.

Estado: en desarrollo. Ver `docs/SPEC.md` para el diseño y `odd/tasks/fondo-salario-app.md` para el avance.

Este repositorio no contiene datos reales ni documentos externos.
